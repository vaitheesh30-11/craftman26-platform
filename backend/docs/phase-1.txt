Pydantic V2 Data Transfer Object (DTO) ContractsAll DTOs must use Pydantic V2 ConfigDict and strict type hints.5.1 AWSConnectionProfileCreateDTO (Inbound Input)account_id: String (exactly 12 digits, validated via regex).account_name: String (1 to 255 chars).organization_id: String (valid AWS Org ID pattern o-[a-z0-9]{10,32}).cross_account_role_arn: String (valid IAM Role ARN syntax).external_id: String (min length 16 chars).kms_key_arn: String (valid KMS Key ARN syntax).5.2 SessionStateCreateDTO (Inbound Ingestion Payload)session_id: String (Unique execution UUID).account_id: String (12-digit AWS Account ID).active_problem_id: String (Enum constraint: SCP-1, SCP-2, SCP-3, SCP-4, SCP-5, IAM-1, IAM-2, IAM-3).target_arn: String (Resource ARN).baseline_policy_json: String (Raw policy JSON string).problem_telemetry: Dictionary matching the payload schemas defined in Section 4.5.3 SessionDetailResponseDTO (Outbound API Response)id: UUID.session_id: String.account_id: String.active_problem_id: String.status: String.target_arn: String.baseline_policy_json: Optional String.working_policy_json: Optional String.zelkova_status: Optional String.blast_radius_score: Optional Float.problem_telemetry: Dictionary.state_tensor_snapshot: Dictionary matching WorkingMemoryState.created_at: DateTime.updated_at: DateTime.6. 6.1 Boto3 AssumeRole Session Factory (boto3_session_factory.py)Purpose: Generates temporary, isolated AWS SDK sessions for target managed accounts.Mechanism: Reads cross_account_role_arn and external_id from aws_connection_profiles table, invokes sts:AssumeRole, and returns a scoped boto3.Session instance with 1-hour credentials.6.2 Amazon Neptune Graph Connector (neptune_connector.py)Purpose: Manages connection pools to Amazon Neptune for executing openCypher graph queries.Configuration: Connects via HTTPS to Neptune cluster endpoint in private VPC subnets using AWS IAM SigV4 authentication.6.3 Amazon OpenSearch Serverless Connector (opensearch_connector.py)Purpose: Connects to OpenSearch Serverless vector search collections.Configuration: Uses SigV4 authentication over HTTPS to execute kNN vector similarity queries on governance-context-v1 index.7. Execution Directives for CodexWhen generating Phase B1 code:Environment Config (backend/app/core/config.py):Use pydantic-settings to load POSTGRES_USER, POSTGRES_PASSWORD, POSTGRES_HOST, POSTGRES_PORT, POSTGRES_DB, and AWS_REGION.Database Engine Setup (backend/app/core/db_setup.py):Construct asynchronous database connection URL using postgresql+asyncpg://.Create AsyncEngine with pool_size=20 and max_overflow=10.Define get_db_session() dependency generator yielding AsyncSession instances.Declarative Models (backend/app/models/):Implement base.py with declarative class mapping.Implement aws_profile.py, session_record.py, and audit_log.py using SQLAlchemy 2.0 Mapped[...] and mapped_column(...).Pydantic Schemas (backend/app/schemas/):Implement all DTOs with strict validation rules and model_config = ConfigDict(from_attributes=True).Alembic Migrations (alembic/):Configure env.py to import declarative metadata and execute migrations asynchronously using run_migrations_online().
