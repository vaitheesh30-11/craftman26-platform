## 4. Custom Node & Edge Specifications

React Flow must be configured to use custom components rather than default circles/rectangles.

### 4.1 Custom Nodes (`AWSAccountNode`, `IAMRoleNode`)
* **Design:** Glassmorphic rounded rectangles with Lucide React icons.
* **Handles:** Hidden by default. Nodes act as rigid blocks in the DAG layout.
* **Data Props:**
  * `label`: String (e.g., `prod-db-role`).
  * `type`: Enum (`ACCOUNT`, `OU`, `ROLE`, `EXTERNAL_VENDOR`).
  * `isCompromised`: Boolean (Determines if the node glows red).
* **Interactivity:** Clicking a node opens a slide-out side panel displaying the raw attached IAM policies for that specific hop.

### 4.2 Custom Edge (`TrustEdge.tsx`)
* **Mapping:** Represents the `ASSUMES_ROLE` relationship.
* **Visual States:**
  1. **Standard Trust (Safe):** Solid Slate line (`stroke-zinc-500`).
  2. **Missing Condition Keys (Vulnerable):** Animated dashed line. Stroke color is Crimson Red (`stroke-rose-500`) with an animated SVG stroke-dashoffset to simulate active lateral movement.
  3. **Hover State:** Thickens the stroke width and displays a tooltip floating over the edge showing the exact missing `aws:SourceArn` value.

## 5. The Neptune JSON Normalizer (`useNeptuneParser.ts`)

The backend (from Phase B1) delivers GraphRAG data in a nested dictionary format. Codex must write a pure transformation function to flatten this for React Flow.

### Input Data (Backend Telemetry)
The hook receives an array of path objects:
`[{ source: "RoleA", target: "RoleB", relation: "ASSUMES_ROLE", isVulnerable: true }]`

### Output Data (React Flow State)
* **`nodes` Array:** Deduplicates all sources and targets. Assigns sequential IDs.
* **`edges` Array:** Maps relations to source/target IDs. Attaches the `animated: true` flag if `isVulnerable` is true.
