4. WebSocket Custom Hook Specification (useWebSocketStream.ts)
This hook acts as the sole manager for the browser's WebSocket API connection to the FastAPI backend.

4.1 Interface Contract
Input Parameters: sessionId: string (derived from URL params), enabled: boolean (controls when to open the socket).

Return State Payload:

connectionState: Enum representing the connection health.

pingLatencyMs: Integer representing network lag.

latestEvents: Array of parsed event dictionaries.

4.2 Reconnection & Resilience Protocol
Initial Connection: Appends the HTTP-only JWT token directly into the connection query string (e.g., wss://api.../ws/drift/{sessionId}?token={jwt}).

Heartbeat Tracking: Dispatches a minimal ping frame every 10 seconds. Expects a pong response within 5 seconds. If missed, transitions state to RECONNECTING.

Exponential Backoff Engine: Auto-reconnect attempts scale from 1s, 2s, 4s, 8s, up to a ceiling of 16 seconds.

State Reconciliation: Upon successful reconnection, automatically requests the STATE_SYNC payload from Backend Phase B3 to backfill any events missed during the network drop.

5. Framer Motion Animated Components
5.1 The Agent Debate Feed (AgentDebateFeed.tsx & DebateCard.tsx)
Animation Library: Uses framer-motion's <AnimatePresence> for list rendering.

Entry Physics:

Initial Mount: opacity: 0, y: 20, scale: 0.98.

Animate In: opacity: 1, y: 0, scale: 1.

Transition: type: "spring", stiffness: 400, damping: 25.

Card Anatomy:

Header: Displays the assigned Coalition Pill Badge, the specific Agent ID, and execution duration (e.g., 340ms).

Body: Clean typography displaying the agent's action or reasoning.

Drawer: An expandable Radix UI Accordion revealing raw tool parameters, SMT solver counter-examples, or JSON snippets wrapped in monospace code blocks.

5.2 Top Telemetry Bar (ExecutionMetricsBar.tsx)
A sticky header component tracking the engine's macro performance.

Debate Iteration Gauge: A circular progress SVG visualizing Turn X of 3.

Quota Compression Metric: A dynamic text counter showing current policy bytes against the 10,240-byte ceiling.

Zelkova Badge: Dynamic badge swapping between Green (PASS) or Red (VIOLATION) with an alert count integer.

Blast Radius Heatmap: A horizontal risk bar shading from green to red based on the incident's calculated risk score.
