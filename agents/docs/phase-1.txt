2. Directory Layout & Module Responsibilities
Codex must generate the Phase 1 Agentic layer within this exact structure:

agents/

core/

config.py — Environment configuration for LLM orchestration (Anthropic Claude 3.5 / AWS Bedrock models, temperature, max token limits).

state/

memory_state.py — The primary LangGraph WorkingMemoryState TypedDict definition with Annotated reducers.

schemas.py — Pydantic V2 models for structured outputs emitted by individual agents (AST diffs, SMT proof requests, RAG contexts).

nodes/

base_node.py — Abstract async node class enforcing token tracking, error boundary handling, and standardized state logging.

graph/

builder.py — LangGraph StateGraph(WorkingMemoryState) builder skeleton, entry point configuration, and checkpointer binding.

3. Working Memory State Tensor Specification (agents/state/memory_state.py)
The multi-agent system uses a single, shared state tensor defined as a LangGraph-compatible TypedDict. State mutations must use explicit reducers (operator.add for lists, default replacement for single values).

Python
import operator
from typing import Annotated, Any, Dict, List, Literal, Optional, TypedDict

class WorkingMemoryState(TypedDict):
    # --- Session & Identity Identifiers ---
    session_id: str
    active_problem_id: Literal[
        "SCP-1", "SCP-2", "SCP-3", "SCP-4", 
        "SCP-5", "IAM-1", "IAM-2", "IAM-3"
    ]
    account_id: str
    target_arn: str
    
    # --- Active Policy Payload State ---
    baseline_policy_json: str
    working_policy_json: str
    
    # --- Problem-Specific Input Telemetry (Matches Backend Schema) ---
    problem_telemetry: Dict[str, Any]
    
    # --- Multi-Agent Debate & Turn History (Append-Only Reducer) ---
    debate_log: Annotated[List[Dict[str, Any]], operator.add]
    coalition_feedback: Annotated[List[Dict[str, Any]], operator.add]
    
    # --- Formal Verification & Safety State ---
    zelkova_status: Literal["PASS", "FAIL_PRIVILEGE_ESCALATION", "UNVERIFIED"]
    counter_examples: List[str]
    blast_radius_score: float
    
    # --- Loop Control & Limits ---
    current_turn_count: int
    max_turns: int
    
    # --- HITL Approval & Interrupt Control ---
    awaiting_hitl_approval: bool
    human_override_payload: Optional[Dict[str, Any]]
    
    # --- Overall Execution Lifecycle Status ---
    execution_status: Literal[
        "ROUTING", "SYNTHESIZING", "SIMULATING", 
        "NEGOTIATING", "AWAITING_HITL", "COMMITTED", "FAILED"
    ]
4. Agent Structured Output Contracts (agents/state/schemas.py)
Agents must enforce structured Pydantic V2 outputs before pushing updates into WorkingMemoryState.

4.1 AgentTurnFeedbackDTO
coalition: String (SUPERVISOR, ALPHA_SYNTHESIS, BETA_SIMULATION, GAMMA_CONTEXT).

agent_id: String (e.g., AST_Compiler_Agent, Zelkova_Prover_Agent).

action_taken: String (High-level summary of node operation).

reasoning_step: String (Short text explanation of the agent's logic).

proposed_policy_json: Optional String (Minified JSON if policy was altered).

execution_time_ms: Float.

4.2 ZelkovaProofResultDTO
status: String (PASS, FAIL_PRIVILEGE_ESCALATION).

counter_example_paths: List of Strings (Human-readable explanations if privilege escalation occurred).

evaluation_latency_ms: Float.

5. Base Node Abstract Interface (agents/nodes/base_node.py)
All subsequent agents (Supervisor, Coalition Alpha, Beta, Gamma) must inherit from BaseAgentNode.

Core Responsibilities
Async Execution: Implements async def __call__(self, state: WorkingMemoryState) -> Dict[str, Any].

Turn Limit Guardrail: Checks state["current_turn_count"] >= state["max_turns"]. If exceeded, automatically sets execution_status = "FAILED" and routes to the termination node.

Telemetry & Error Wrapper: Wraps node logic in try/except. On error, appends an error dictionary to debate_log with stack trace information without crashing the overall LangGraph execution loop.

7. Execution Directives for Codex
When assigning Phase 1 of the Agentic Engine to Codex, instruct it to:

Build Config (agents/core/config.py):

Set up pydantic-settings to manage LLM keys (ANTHROPIC_API_KEY, OPENAI_API_KEY, AWS_REGION).

Build Memory State (agents/state/memory_state.py):

Implement WorkingMemoryState using TypedDict and Annotated[..., operator.add] for the append-only log fields.

Build Pydantic Schemas (agents/state/schemas.py):

Write AgentTurnFeedbackDTO and ZelkovaProofResultDTO using strict Pydantic V2 models.

Build Base Node (agents/nodes/base_node.py):

Implement the BaseAgentNode abstract class containing error handling, turn counting, and execution duration measurement.

Build Graph Skeleton (agents/graph/builder.py):

Set up build_sentinel_graph() instantiating StateGraph(WorkingMemoryState) and registering a MemorySaver checkpointer for local development.
