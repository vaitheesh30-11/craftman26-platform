### 3.1 Semantic Attribute Standard
Every span emitted by the Agentic Engine MUST include these standardized key-value pairs:
* `sentinel.session_id`: Unique string identifying the working memory session.
* `sentinel.active_problem_id`: Target problem statement (`SCP-1` through `IAM-3`).
* `sentinel.active_coalition`: `"SUPERVISOR" | "ALPHA_SYNTHESIS" | "BETA_SIMULATION" | "GAMMA_CONTEXT"`.
* `sentinel.agent_id`: Agent identifier (e.g., `"AST_Compiler_Agent"`).
* `sentinel.loop_count`: Current debate turn iteration index ($0, 1, 2, 3$).
* `sentinel.zelkova_proof_status`: `"PASS" | "FAIL_PRIVILEGE_ESCALATION" | "UNVERIFIED"`.
* `sentinel.policy_byte_size`: Integer byte length of the working policy AST.
* `llm.token_count.prompt`: Number of input tokens passed to Bedrock.
* `llm.token_count.completion`: Number of output tokens generated by Bedrock.
* `llm.cost_usd`: Calculated financial cost of the LLM invocation.

## 4. LLMOps & FinOps Cost Tracking Model

The `token_tracker.py` module tracks model token usage in real time, preventing budget overruns during self-correction loops.


```

[Agent Invokes LLM]
│
▼
┌────────────────────────────────────────────────┐
│ EXTRACT TOKEN USAGE METRICS                    │
│ - Prompt Tokens ($P_{in}$)                     │
│ - Completion Tokens ($P_{out}$)                │
└────────────────────────┬───────────────────────┘
│
▼
┌────────────────────────────────────────────────┐
│ CALCULATE FINANCIAL COST                       │
│ $\text{Cost} = (P_{in} \times C_{in}) + (P_{out} \times C_{out})$ │
└────────────────────────┬───────────────────────┘
│
▼
┌────────────────────────────────────────────────┐
│ SESSION BUDGET CHECK                           │
│ Is Session Cost > $1.50 USD Limit?             │
└────────────────────────┬───────────────────────┘
/                            

YES                             NO
/                                

v                                  v
[TRIGGER CIRCUIT BREAKER]          [UPDATE OTEL METRICS]

* Halt debate loop                 - Emit CloudWatch Metric
* Force HITL escalation            - Continue execution

```

### FinOps Circuit Breakers
1. **Per-Session Budget Ceiling:** Hard budget limit of **$1.50 USD** per resolution session. Exceeding this limit halts the debate loop and escalates the session to human administrators with a `BUDGET_EXCEEDED` tag.
2. **Global Hourly Safety Cap:** CloudWatch Alarms track aggregate hourly spend across all tasks. If spend exceeds $100/hour, auto-scaling caps maximum ECS Fargate task concurrency to prevent runaway billing.

| Metric Name | Type | Description | Operational SLI/SLA Target |

## 6. Semantic Drift & Quality Degradation Detection

The `drift_detector.py` module monitors agent performance over time to detect reasoning decay caused by model updates or prompt modifications.


```

[Execution Session Completed]
│
▼
┌────────────────────────────────────────────────┐
│ EXTRACT PERFORMANCE VECTOR                     │
│ - Zelkova SMT Proof Status                     │
│ - Debate Loops Required                        │
│ - Output AST Byte Minification Ratio           │
└────────────────────────┬───────────────────────┘
│
▼
┌────────────────────────────────────────────────┐
│ COMPARE AGAINST HISTORICAL BASELINE            │
│ Evaluates performance against moving average   │
│ over last 1,000 sessions                       │
└────────────────────────┬───────────────────────┘
/                            

[Drift Detected:               [Performance Nominal:
Pass Rate Drop > 5%]           Pass Rate Normal]
/                                

v                                  v
[EMIT ALARM]                     [LOG METRICS]

* Trigger Slack Alert            - Update baseline vector
* Log regression state           - Continue tracking

```

### Automated Drift Alarms
* **SMT Proof Convergence Alarm:** Triggers if the percentage of policies passing Zelkova within 3 turns drops below 90% over a 24-hour window.
* **Minification Efficiency Alarm:** Triggers if average SCP byte compression drops below 20% compared to baseline.
* **Latency Anomaly Alarm:** Triggers if SMT solver execution times or LLM response latencies exceed $3\sigma$ from historical moving averages.

## 7. Execution Directives for Codex

When generating Phase 7 Observability, AgentOps, and Telemetry modules:

1. **Tracing Implementation (`agents/observability/tracing/`):**
   * Build `langgraph_tracer.py` using OpenTelemetry Python SDK (`opentelemetry.trace`) to automatically instrument LangGraph state transitions and agent turns.
   * Define standardized span attributes in `span_attributes.py`.
2. **Metrics & FinOps (`agents/observability/metrics/`):**
   * Build `token_tracker.py` to calculate exact cost models for Anthropic Claude 3.5 Sonnet invocations and enforce the $1.50 session budget limit.
   * Build `convergence_metrics.py` to measure debate turns, SMT solver latency, and first-pass pass rates.
3. **Drift Detection (`agents/observability/guardrails_telemetry/`):**
   * Build `drift_detector.py` to compare real-time session outcomes against rolling historical baselines and flag quality regressions.
4. **Exporters (`agents/observability/exporters/`):**
   * Build `OTEL_collector.py` to package and export traces/metrics to Amazon CloudWatch, AWS X-Ray, or external OpenTelemetry collectors with credential redaction filters.
