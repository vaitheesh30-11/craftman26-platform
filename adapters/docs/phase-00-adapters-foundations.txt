PHASE 00 — Adapters Foundations
================================

Owner assumption: one principal engineer. Duration: 2 days.

------------
Stand up the Python package that every downstream adapter (bedrock, zelkova, prompts, evidence, ddb) inherits from. Ships `settings.py`, `errors.py`, `retry.py`, `circuit_breaker.py`, `cost_meter.py`, and the test scaffolding.

3. Exception Hierarchy
----------------------
```python
class SentinelAdapterError(Exception): ...
class TransientError(SentinelAdapterError): ...
class ThrottlingError(TransientError): ...
class NetworkError(TransientError): ...
class NonRetryableError(SentinelAdapterError): ...
class AccessDeniedError(NonRetryableError): ...
class ValidationError(NonRetryableError): ...
class GuardrailInterventionError(NonRetryableError): ...
class ZelkovaError(SentinelAdapterError): ...
class ZelkovaViolationError(ZelkovaError): ...
class BudgetExceededError(SentinelAdapterError): ...
class CircuitOpenError(SentinelAdapterError): ...
class SanitizerRejection(SentinelAdapterError): ...
```

Every adapter surface method translates boto3 exceptions to one of the above at the boundary. Callers never see raw `botocore.exceptions.ClientError`.

4. Retry Policies
-----------------
Policies encoded in `retry.py`:

```python
class Policy(Enum):
    AGGRESSIVE = ("aggressive", 5, 0.2, 2.0, 5.0, 0.25)
    CAUTIOUS   = ("cautious",   3, 0.5, 3.0, 10.0, 0.20)
    SINGLE     = ("single",     1, 0.2, 1.0, 0.2, 0.0)
    NONE       = ("none",       0, 0.0, 1.0, 0.0, 0.0)

def retry(*, policy: Policy, retry_on: tuple[type[Exception], ...] = (TransientError,)):
    """Decorator wrapping tenacity with jitter and total-time cap."""
```

Hard rules:
- Every policy has a total-time cap enforced via `stop_after_delay`.
- `NONE` executes zero retries.
- Any `AccessDeniedError`, `ValidationError`, `GuardrailInterventionError`, `SanitizerRejection` short-circuits retries regardless of policy.

5. Cost Meter
-------------
```python
class CostMeter:
    def record(self, correlation_id: str, kind: SpendKind, amount: float) -> None: ...
    def projected(self, correlation_id: str) -> float: ...
    def check_budget(self, correlation_id: str, kind: SpendKind, delta: float) -> None: ...
    # raises BudgetExceededError if delta would push over cap
```

Implementation:
- `record` emits an EMF metric (`SentinelSpend[kind]`) with dimensions `feature_id, principal, mode`.
- Also appends a `SpendSample` to DDB `SentinelBudget` (PK=correlation_id, SK=ULID).
- `projected` sums same-correlation samples from DDB (cached 5 seconds in-process).
- `check_budget` reads caps from SSM `/sentinel/budget/*`, refreshed 5 minutes.

6. Circuit Breaker Accessor
---------------------------
```python
class BreakerAccessor:
    def state(self, breaker_name: str) -> Literal["closed","half_open","open"]: ...
    def record_success(self, breaker_name: str) -> None: ...
    def record_failure(self, breaker_name: str) -> None: ...
    def trip(self, breaker_name: str, reason: str) -> None: ...
```

Implementation: DDB `SentinelBreakers` (PK=breaker_name). Transitions: 3 failures in 60 s → open (5 min) → half_open (1 probe) → closed on success.

10. Risks & Mitigations
-----------------------
Risk: SSM refresh latency starves fast-path.
  Mitigation: 5-min in-process cache; SSM param fetch runs on background timer, not per-call.

Risk: DDB budget writes throttle under load.
  Mitigation: write via best-effort (background thread); metric emission is authoritative for real-time accounting.

Risk: tenacity behavior surprises on nested decorators.
  Mitigation: retry decorator applied at exactly one layer per method; unit tests cover nested-invocation regressions.
